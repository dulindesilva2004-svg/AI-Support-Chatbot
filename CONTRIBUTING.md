# Contributing

1. Pick a task in Jira and move it to **In Progress**.
2. Create a branch from `develop`: `git checkout -b feature/CHAT-12-short-name`
3. Commit with the Jira key at the start: `CHAT-12 Add returns intent`
4. Push and open a Pull Request into `develop`. Fill in the template.
5. Get one teammate to review and approve, then merge.
6. Move the Jira task to **Done**.
